RULE 07

-F: two possible forms

Екі нұсқасы кездесетін -F сөздері

Кейбір сөздерде -s те, -ves те кездеседі. Мұндай сөздерді тестте бір ғана форма дұрыс деп беруге болмайды.

Мысалдар

hoof → hoofs / hoovesтұяқ → тұяқтар
wharf → wharfs / wharvesайлақ → айлақтар
COMPARE · F / FE
knife → knivesroof → roofsscarf → scarfs / scarves
Барлық -f/-fe сөздеріне бір ғана ереже қолданылмайды. Осы үш модельді салыстырып есте сақта.

RULE 11

Same singular & plural form

Жекеше және көпше формасы бірдей

Кейбір зат есімдер көпше түрде өзгермейді. Санын контекст пен сан есімнен анықтаймыз: one sheep → five sheep, one deer → two deer, one fish → ten fish.

Назар аудар: қарапайым «бірнеше балық» мағынасында fish қолданылады. Fishes әртүрлі балық түрлерін арнайы ажыратқанда кездесуі мүмкін.

Мысалдар

sheep → sheepқой → қойлар
deer → deerбұғы → бұғылар
fish → fishбалық → балықтар
series → seriesсерия → сериялар
species → speciesтүр → түрлер
TEST 11

Жауабы мен талдауы
Дұрыс жауап: B) deer.

Deer singular және plural түрде бірдей: one deer → six deer.
